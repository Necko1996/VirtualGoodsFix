# Virtual Goods Fix

Impose limit of househols spending on virtual goods and limits the overall househols spendings

### What does this mod do?

- Impose limit on daily spending on virtual goods based on income of Household
- Impose limit on househould how much virtual goods can be purchused at once, based on size of Household
- Reserves 2x rent of Household
- Impose limit on 25% of Household surplus on spending on any purchases
- Fixing a bug on TradeCost, resulting in not changing TradeCost if order is failed/canceled
- Fixing other bugs and boost performance a bit
